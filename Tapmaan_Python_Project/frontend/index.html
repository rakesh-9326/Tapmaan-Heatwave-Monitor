Understand the warning levels

These temperature-only thresholds demonstrate the project logic. They are not IMD’s official heatwave criteria. Humidity is displayed but does not change this score.

NormalBelow 35°C
Watch35 to <40°C
High40 to <45°C
Severe45°C and above

What the model actually does

LinearTrendModel fits a straight line to recent observations using least squares. It estimates the temperature three hours later. Sample, live and manual data are never combined for training. The 24-hour outlook comes from the selected weather provider, separately from this small learning model.

Sample mode uses a fixed, fictional May 2026 scenario. Live mode in the local Python project requests Open-Meteo data; its current and historical values are model-based estimates, not readings from a physical sensor.
